# Second Brain OS — project context (source of truth for promo videos)

Owner: Ethan. Product: a Notion template "Second Brain OS", sold on Gumroad (+ promoted on TikTok).
Everything in the template is in ENGLISH. Launch price 19 EUR, then 29 EUR. Link goes "in bio".

## What the template really contains
- Home page: embedded HTML block with a 3D brain made of white bars (three.js), black background (#07080b), monospace font,
  rotates with the finger. Touching a label shows a 3D "OPEN" button at the bottom. Under it, a grey callout with 12 native Notion
  links to the categories. Sub-page "Behind the scenes" holds the 12 category pages, 5 guides, 3 quick views.
- 12 category pages, each with an animated canvas header, intro, "How to use it", "Avoid", then the embedded database:
  Inbox, Projects, Areas, Resources, Archive, Notes, Tasks, Goals, Journal, Habits, Library, Ideas.
- Databases are linked together and contain example data:
  - Projects: Progress = rollup % of Done tasks, Days left = formula.
  - Tasks: Alert formula (Overdue / Today); views Board, By energy, Calendar.
  - Notes: CODE status. Habits: Score formula. Areas, Goals, Resources, Library, Inbox, Ideas, Journal, Archive.
- Guides: Start here, The PARA method, The CODE method (credit Tiago Forte), Weekly review, Monthly review.
- Security audit done: no API key / token / personal data in the template.
